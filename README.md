# Web Development Internship Projects

This repository contains three web development projects completed during my internship. These projects were developed to strengthen frontend development skills using HTML, CSS, and JavaScript while focusing on responsive design, user experience, and functionality.

---

# Projects Included

## 1. Restaurant Landing Page

### Overview

A modern and responsive restaurant landing page designed to showcase a restaurant's brand, menu, services, and contact information. The website provides an attractive user interface to engage visitors and potential customers.

### Features

* Responsive design for mobile and desktop devices
* Hero section with call-to-action buttons
* About section
* Menu showcase
* Contact information section
* Smooth navigation
* Modern UI design

### Technologies Used

* HTML5
* CSS3
* JavaScript
